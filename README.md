# MOBAPP - Mobile App Landing Page

A mobile app landing page developed during my internship using HTML5 and Tailwind CSS.

## Features

- Responsive navigation bar
- Gradient hero section
- Mobile app showcase
- Client logos section
- Features section
- Modern landing page design
- Tailwind CSS utility classes

## Technologies Used

- HTML5
- Tailwind CSS

## Project Structure

```text
mobapp-landing-page/
│
├── landingpage2.html
├── README.md
│
└── assets/
    ├── iphonex.png
    └── client-logos.png
```

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `landingpage2.html` in a web browser.

No installation or build process is required.
